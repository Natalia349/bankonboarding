Блок заданий №1. Тренировка в создании методов контроллеров, сервисов, обработка исключений

1.1) Сделать метод GET /welcome который отдает http code 200 c json объектом { "message": "Добро пожаловать в наш чудесный магазин" }

1.2) Сделать метод GET /product который отдает массив подготовленных продуктов со следующей информацией: идентификатор товара, название, цена за единицу

1.3) Сделать метод POST /calc - метод принимает массив объектов (идентификатор товара, количество) и отдает объект с итоговой суммой и массивом товаров (название товара, цена за единицу, количество, сумма). Если во входных значениях есть идентификатор с несуществующим товаром, то необходимо выдать ошибку http code 400 с объектом содержащим информацию о несуществующем товаре. Здесь необходимо воспользоваться Исключениями и ExceptionHandler
